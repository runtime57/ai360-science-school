# AI-360 Science School

A two-week intensive course for second-year students. During the course, they:

- learn the fundamentals of deep learning;
- study relevant literature and lecture materials;
- reproduce research results by implementing Transformer and RoFormer models;
- conduct ablation studies.

Through this work, students learn the basics of deep learning research and gain a deeper understanding of the Transformer architecture and RoPE, which are widely used in frontier LLMs.

---

### Workflow

All work will be done in the [ai360-transformer repository](https://github.com/runtime57/ai360-transformer).

Create a separate branch for your work using the `{handle}/{branch-name}` naming convention. For example, create a branch for your image classification implementation by running:

```bash
# Replace runtime57 with your own handle
git checkout -b runtime57/image-classification
```

This way, I will have quick access to your code and will be able to help you or offer advice.

Notes that you create during reading the paper you can also store in your own branch `handle/papers`.

> **Tip:** Don't be afraid to commit your progress regularly — it is better to have too many commits than too few.
